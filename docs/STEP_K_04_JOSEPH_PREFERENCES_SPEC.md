## 1. Scope and Architectural Boundaries
- **Not Old Lucie Chat Migration:** This pipeline does NOT import chat logs into `chat_session` or `chat_message`. It is purely an offline analysis workflow to refine tone and prompt configuration.
- **No Direct Mass Database Ingestion:** Joseph's ChatGPT history will never be bulk-uploaded into NeonDB.
- **No Vector / RAG Systems:** Per Step K boundaries, no vector databases, embeddings, Pinecone instances, or `pgvector` extensions will be introduced.
- **Fact Verification Boundary:** Assistant-generated statements in ChatGPT transcripts must NEVER be treated as verified mortgage rules, official licensing disclosures, or broker guidelines without Joseph's explicit confirmation[cite: 2].
- **Log & Prompt Boundary:** Confidential or unredacted client transcripts must never appear in production server logs, application prompt contexts, or code commits[cite: 2].

## 4. Five Derived Artifact Specifications

Every analyzed conversation produces five structured artifacts[cite: 2]:

1. **Per-Example Provenance & Annotations:** Records source chat ID/title, user prompt, assistant response, and Joseph's specific feedback or rating[cite: 2].
2. **Pattern Summary:** Quantifiable stylistic metrics covering tone, framing, length, call-to-action (CTA), emoji density, and intended audience[cite: 2].
3. **Recommended `brand_profile` and `persona` Edits:** Exact proposed text changes to the existing schema fields (`brand_voice`, `approved_phrases`, `prohibited_phrases`)[cite: 2].
4. **Joseph-Approved Writing Examples:** 2 to 3 curated exemplar posts that demonstrate his preferred rhythm, used as few-shot reference context[cite: 2].
5. **Unanswered Questions for Review:** Explicit list of style ambiguities, compliance edge-cases, or assumptions requiring Joseph's confirmation[cite: 2].

## 5. Consent, Redaction & Review Checklist

Before any extracted preference is presented to Joseph or committed to configuration, the operator must verify this checklist[cite: 2]:

- [ ] **Consent Verified:** Joseph explicitly consented to the analysis of the provided chat export for tuning Lucie[cite: 2].
- [ ] **PII Redaction:** Transcripts scrubbed of borrower names, phone numbers, loan balances, credit scores, and property street addresses.
- [ ] **No Unverified Factual Claims:** Any rate quote, guideline threshold (e.g., FHA debt-to-income limits), or loan program parameter generated by ChatGPT is flagged as unverified until Joseph confirms it[cite: 2].
- [ ] **No Raw Transcripts in Prompts:** Raw conversation logs are excluded from generation prompts; only approved style instructions and sanitized few-shot exemplars are retained[cite: 2].
- [ ] **Human-in-the-Loop Review:** The final profile is editable, versioned, and requires explicit sign-off from Joseph before database insertion[cite: 2].
